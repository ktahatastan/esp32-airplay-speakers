# İş kırılımı

- Donanım: sürücü ölçümü; kart/pin; DAC + dört amfi; güç girişi (24 V / 2,9 A adaptör, jak, iki 5 V buck); dört amfinin paralel girişleri ve `VIN` dağıtımı; EMI.
- Firmware: AirPlay prototipi; DSP/limiter; provisioning; UI; NVS; GitHub Actions release hattı; imzalı A/B OTA; canary/stable dağıtım; rollback/recovery.
- Mekanik/akustik: pasif radyatörlü kabin, sekiz sürücünün yerleşimi, akort ve ölçüm iterasyonu.
- Süreç: BOM, ADR, günlük, handoff ve test kanıtları.

Her alt görev ölçülebilir başarı kriteri, dosya sahibi ve gerekli gate ile açılır.
